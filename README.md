# Bank Operations Widget

Виджет для работы с банковскими операциями клиента: фильтрация и сортировка
списка операций по статусу и дате.

## Цель проекта

Учебный проект по разработке виджета банковских операций с соблюдением
GitFlow, PEP 8, атомарных коммитов и код-ревью через pull request.

## Требования

- Python 3.10+
- pip (в Windows вызывается как `py -m pip`)
